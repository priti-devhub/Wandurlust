# 🌍 Wanderlust

Wanderlust is a full-stack web application inspired by Airbnb, where users can explore destinations, create listings, upload images, and share their experiences through reviews.

## ✨ Features

- 🔐 User Authentication
- 🏠 Create, Edit, and Delete Listings
- 📸 Image Upload with Cloudinary
- ⭐ Reviews and Ratings
- 📱 Responsive User Interface

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript, EJS
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose

## 🚀 Run Locally

```bash
npm install
node app.js
```
